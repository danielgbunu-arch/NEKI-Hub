
# Java - NEKI Hub

## Descripción

Esta carpeta contiene el desarrollo del algoritmo en lenguaje Java para el proyecto NEKI Hub, un sistema inteligente de seguridad y control de acceso para negocios.

## Objetivo

Implementar mediante Java la lógica de funcionamiento de un sistema de seguridad que permita gestionar el ingreso de personas y controlar la apertura de puertas.

## Funcionalidades del sistema

- Detección de personas mediante sensores.
- Registro y conteo de personas que ingresan.
- Apertura automática de puertas.
- Apertura mediante comandos de voz.
- Apertura mediante pulsador manual.
- Gestión de los estados del sistema.
- Notificación de eventos y errores.

## Desarrollo

El código Java representa la implementación de la lógica del sistema NEKI Hub.

En esta carpeta se almacenarán los archivos .java desarrollados por el equipo.
