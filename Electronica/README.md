# Electrónica - NEKI Hub

Esta carpeta contiene el código utilizado para programar el ESP32 de nuestro proyecto NEKI Hub.

NEKI Hub es un sistema inteligente de seguridad y control de acceso para negocios.

El ESP32 permite controlar:
- Sensores de presencia para detectar personas.
- Apertura automática de puertas.
- Luces LED indicadoras del estado del sistema.
- Zumbador para emitir alertas sonoras.
- Pulsador para la apertura manual.
- Comunicación con la computadora mediante USB.

Aquí se almacenará el código fuente del ESP32 utilizado en el prototipo físico.
