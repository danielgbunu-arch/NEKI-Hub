# PSeInt - NEKI Hub

## Descripción

Esta carpeta contiene los algoritmos y pseudocódigos desarrollados en PSeInt para el proyecto NEKI Hub.

NEKI Hub es un sistema inteligente de seguridad y control de acceso diseñado para mejorar la gestión del ingreso de personas a establecimientos comerciales.

## Objetivo

Diseñar la lógica de funcionamiento del sistema mediante algoritmos estructurados antes de su implementación en lenguajes de programación.

## Procesos representados

- Inicialización del sistema de seguridad.
- Detección de personas.
- Conteo y registro de entradas.
- Control de apertura y cierre de puertas.
- Procesamiento de comandos de apertura.
- Activación de indicadores luminosos.
- Gestión de alertas.
- Control de apertura manual.

## Estructuras de programación

Los algoritmos podrán utilizar:

- Estructuras secuenciales.
- Condicionales Si-Entonces-Sino.
- Estructura Segun.
- Ciclos Mientras, Repetir y Para.
- Variables y contadores.
- Subprocesos y funciones.

## Desarrollo

En esta carpeta se almacenarán los archivos .psc correspondientes a los algoritmos desarrollados por el equipo.
